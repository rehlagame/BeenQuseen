# ( بين قوسين )

> **بين قوسين صفحة رقمية لعمود سياسي ساخر يُكتب بالذكاء الاصطناعي بدون تدخل بشري ليعكس الصحافة المستقبلية بحدود الأدب واللوائح المحلية والذوق العام**

## فكرة المشروع
مدونة صحفية رقمية تنشر آلياً عموداً سياسياً ساخراً يومياً في تمام **الساعة 10:00 مساءً بتوقيت دولة الكويت (`Asia/Kuwait`)**، يركز حصرياً على السياسة الدولية وتناقضات القوى الكبرى (أمريكا، إيران، روسيا، أوكرانيا، أوروبا، الناتو، كوريا الشمالية، الصين، والأمم المتحدة) بأسلوب صحفي مشاغب وساخر.

## هيكلية النشر على GitHub و Vercel

المشروع مهيأ بالكامل للعمل مباشرة على **GitHub** و **Vercel** بطريقتين متكاملتين للنشر اليومي الآلي:

1. **مجدول GitHub Actions الآلي (`.github/workflows/daily-column.yml`):**
   - يعمل تلقائياً كل يوم الساعة `19:00 UTC` (**10:00 مساءً بتوقيت الكويت**).
   - يقوم بتوليد عمود الليلة وحفظه في `data/articles.json` وعمل Commit تلقائي إلى المستودع، مما يدفع **Vercel** لتحديث الموقع فوراً خلال ثوانٍ.
   - *(اختياري)*: يمكنك إضافة مفتاح `GEMINI_API_KEY` في إعدادات المستودع (`Settings -> Secrets and variables -> Actions`) ليقوم بتوليد المقالات مباشرة عبر Gemini 2.0 Flash من أخبار اليوم الحية، وبدونه يعمل المحرك المدمج تلقائياً.

2. **دوال Vercel السحابية (`api/articles.js`, `api/react.js`, `api/cron.js`) + `vercel.json`:**
   - تعمل فوراً عند ربط المستودع بـ Vercel بدون أي إعدادات إضافية.
   - تحتوي على آلية فتح تلقائي للأعداد اليومية مع كل دورة ساعة 10:00 مساءً بتوقيت الكويت بدءاً من **العدد الأول (#1)**.

## خطوات الرفع على GitHub ثم Vercel

```bash
git init
git add .
git commit -m "Launch Bayn Qawsayn Edition #1"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

ثم ادخل إلى [Vercel](https://vercel.com) واضغط **Add New Project** واختر المستودع من GitHub واضغط **Deploy**.
